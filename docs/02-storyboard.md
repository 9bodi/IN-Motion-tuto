# 2. Storyboard

Format 1920 × 1080, 16:9, 30 i/s. Durée estimée : **4:02** (à recaler sur la voix off réelle).
Les minutages fins de chaque réplique sont dans [`01-script-voix-off.md`](01-script-voix-off.md).

## Principes visuels (communs à toutes les scènes)

| Élément | Règle |
|---|---|
| Fond / texte | Fond crème clair `#F5F3EE`, texte quasi noir `#15171C` (contraste ≈ 16:1). |
| Accent | Une seule couleur : vert sarcelle `#0E6B5B`. Aucune reprise du jaune ni du bleu La Poste, aucun logo. |
| Typographie | Inter (sans empattement), embarquée localement. Titres 56–104 px, consignes 58 px, détails 32–36 px. |
| Une action à la fois | Zone gauche : **une** consigne. Zone droite : téléphone ou illustration. Les éléments passés sont atténués, jamais en même temps qu'une nouvelle consigne. |
| Téléphone | Smartphone générique de face, sans perspective, 360 × 720 px. Écrans **schématiques** (barres grises à la place des textes, boutons sans libellé). Mention permanente sous l'écran : « Écran illustratif — l'affichage peut varier ». |
| Mise en évidence | Encadré épais + halo qui « respire » lentement + **étiquette texte** (« Recherche », « Installer », « Code secret »…). Jamais de couleur seule. |
| Indicateur d'étape | En haut à gauche : ①②③ avec libellés ; l'étape en cours est pleine, en gras **et soulignée** ; les étapes passées portent ✓. |
| Mentions permanentes | En haut à droite : « Tutoriel indépendant — non officiel ». En version de travail : bandeau rouge « VERSION DE TRAVAIL — voix off non intégrée · informations à valider ». |
| Données personnelles | Uniquement fictives et étiquetées « EXEMPLE FICTIF » / « DOCUMENT FICTIF — SPÉCIMEN ». Numéro de mobile pris dans la plage réservée à la fiction par l'Arcep (06 39 98 xx xx). Aucun code affiché, aucun nombre de chiffres suggéré. |
| Sous-titres | Bas d'écran, fond sombre opaque, blanc 42 px, **2 lignes max** (contrôle automatique à 52 caractères par ligne). Restent au-dessus de tous les autres éléments. |
| Animations | Fondu + glissement de 24 px, ressort amorti sans rebond (≈ 0,6 s). Pas de transition spectaculaire entre scènes : coupe franche sur fond identique. |
| Pauses | Fin de chaque étape : carte « ⏸ À vous ! » plein écran, ≈ 4 s de silence, pour inviter à mettre en pause. |
